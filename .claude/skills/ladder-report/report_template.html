Rigel · 0.8.0 release candidate

End-to-end accuracy, release candidate against 0.7.1

Sixteen simulated libraries of 10,000,000 fragments each, spanning 0–98 % genomic-DNA contamination × two strand specificities × capture on and off, then the two fragment-length gap panels, calibration against an oracle calibration, and one real cell-line mix with per-fragment truth. Every simulated figure is scored against the simulator’s own realised per-fragment truth. The 0.7.1 column is a ballpark: the tagged release scored the same way on the panel’s previous simulation, not on these reads.

Re-simulated on 2026-10-21 with a fairer simulator. No fragment is drawn over sequence the reference does not know: assembly gaps (N) are 18.8 % of the panel’s genome, and the panel before drew about a fifth of its gDNA there as all-N reads, which no aligner places and the simulator’s own alignments placed by truth. Every read now carries substitution errors at 0.2 % per base, and fragment lengths follow the configured law exactly. The fair panel exposes a defect the old one hid: Rigel’s region lengths count those unknown bases, so it under-calls gDNA (by 6–21 % on the contaminated rungs of the three in-scope strata) and books the rest as nascent RNA — an open, release-blocking issue (region-lengths-count-unobservable-bases). Every number here is on the new reads; set beside an earlier card, it compares across simulations.

How to read this

  • Each stratum's headline is its three contaminated rungs (5, 50 and 98 % gDNA): summed |estimate − truth| over the transcript table, against the summed true annotated mass. The 0 % rung is a control and is shown beside it, never folded in.
  • Read per stratum, never pooled. Three strata are in scope. Unstranded × capture ON is deferred: reported everywhere, not a 0.8.0 release requirement, and it carries most of the error.
  • Three pools, three questions. gDNA is contamination to remove; nascent RNA is the synthetic entity the index makes per merged span; annotated RNA is the transcript table a user reads. The split is on is_synthetic.
  • The ceiling arm runs the same pipeline with the EM handed a perfect gDNA prior (oracle); its distance below the release candidate prices what the prior still costs. The capture-length ceiling (oracle_ruler) is withheld: its anchor predates the shipped capture reader and it reads 476 % on the g98 stranded capture-ON row, an instrument defect filed for repair.
  • An effect is judged by its size, genes and pools read beside the transcript table. Every arm runs with the scan pinned (scan.total_threads=1) under fractional assignment, and the locus EM gives one answer at any thread count, so it is exactly reproducible.
  • Two inputs, one truth. Each simulated library is read twice: from the simulator’s own alignments, which place every read where it was drawn, and from STAR alignments of the same reads, the input a real library gives Rigel. Both are scored against the same per-fragment truth, so the columns compare directly. An aligner leaves a little of what was simulated unplaced (about 1.4 % of the gDNA off capture); those fragments are counted apart (unaligned), and the gDNA fraction’s truth is read over what reached Rigel.
  • MARD is symmetric, |est−true| / (|est|+|true|), bounded in [0,1]; 0.5 means a 3× error. It and the median relative error weight a 1-fragment transcript as much as a 25,000-fragment one.

Per stratum

The headline table. Contaminated rungs summed within a stratum, the 0 % control on its own line, and the perfect-prior ceiling beside the release candidate.

02

STAR alignments — the same reads, aligned as a real library is

Per scenario. Σ|Δ| as a share of the true annotated mass on each input; the gDNA fraction on STAR alignments against its truth over the read pairs the aligner placed; and what the aligner left unplaced, by true origin.

03

Pool level — where the fragments went

For each ladder library, its 10 M fragments split three ways: the truth, the release candidate, and 0.7.1 (the thin bar), all to one scale, so mass moving between pools is visible directly.

gDNA (EM + intergenic) Nascent RNA (synthetic entities) Annotated RNA (the transcript table)
04

Transcript level

Inside the annotated pool alone. Σ|Δ| sums |estimate − truth| over every transcript in the truth table, silent ones included; the percentage is that sum against the true annotated mass, with 0.7.1’s beside it.

05

Gene level

The same scorer over genes. Summing a gene’s isoforms removes the error of not knowing which isoform a fragment came from; what survives is error in deciding whether the fragment was RNA from this gene at all.

06

Fragment-length gap panels

The ladder gives gDNA and RNA equal fragment lengths on purpose. These two side panels re-simulate the 50 % rung with RNA fragments longer, or shorter, than gDNA’s, so a length mechanism is judged in both directions. Never a ladder rung; read beside it.

07

Calibration against oracle calibration

The number that ranks a calibration mechanism, upstream of the EM. fgDNA is the library gDNA fraction calibration reads (P) against the origin-split truth (O). MWAE is the mass-weighted absolute error of the per-object gDNA split, on regions and on boundaries. It calibrates each condition's cached scan, built 2026-10-16/17, before the scan's repair; the panels are re-cached once the scan is final.

08

Real data — the VCaP mix

An in-silico blend of two real VCaP libraries, exome DNA and transcriptome, whose read names carry each fragment’s origin. The library gDNA fraction from summary.json.

Pool colours are the data-viz reference palette’s categorical slots 1–3, in fixed order.
