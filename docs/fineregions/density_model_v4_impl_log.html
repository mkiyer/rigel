Phase 3 — DensityModel

done

Edits applied

  • Created src/rigel/calibration/density_model.py with the v4 constants, prior-family codes, flag bits, GammaRatePrior, compact DensityEvidence, and InsufficientAnchors.
  • Implemented fit_gamma_prior using Pearson-scored upper trimming: the trim score is (C - mu)^2 / max(mu, 1e-6), while the MoM estimator still uses the exposure-adjusted (S_trim - B_trim) / A_trim identity on the retained rows. The prior records pearson_chi2_trimmed, trimmed_mu_fraction, cap diagnostics, and all v3 moment fields.
  • Implemented compute_beta_cap, select_rho_ref, the deterministic zero-density branch, vectorised per-region prior assignment (depths 0/1/2), and the v4 weak depth-2 fallback prior Gamma(1, 1 / rho_ref).
  • Implemented local posterior / predictive math with continuous posterior identities, SciPy NB ppf, and the closed-form stop-loss identity. The full diagnostic arrays remain transient; only rho_post, relative_exposure, mean_unbounded, upper_unbounded, and uint8 provenance/flag arrays are stored on DensityEvidence.
  • Added tests/test_density_model.py (18 tests) covering Poisson mean recovery, overdispersed finite phi, phi_floor, Pearson trim vs raw-residual trim, nRNA-contaminated anchors, beta-cap invariants, rho-ref selection, weak fallback shape, deterministic zero evidence, local update, NB predictive agreement, fractional-count convention, closed-form stop-loss, tension flags, generic flag bits, and sparse-family fallback depth.

Deviations / unexpected findings

  • Summary-only diagnostics tension. v4 §7 says the full diagnostic arrays removed from DensityEvidence are computed on-demand for the §8.4 summary from (observation, priors, rho_post, rho_ref), while §8.1 also makes DensityObservation transient and absent from CalibrationResult. Phase 3 preserves the compact evidence dataclass exactly and provides a compact DensityEvidence.to_summary_dict() over stored arrays and priors only. Phase 4 must choose the final summary mechanism: either compute and store summary-only scalar diagnostics during fitting, or let the orchestrator pass the transient observation into a separate summary helper before dropping it. No per-region diagnostic arrays were added.
  • Fractional-count convention clarified in code/tests. The formulas in §7.4 use raw fractional B_tot in the continuous posterior identities and floor C_r for NB SF/PPF tail evaluations. The documented b_int variable is not used by the provided formulas. Phase 3 implements the formulas as written and tests that contained counts with the same floor produce identical tail/stop-loss diagnostics at fixed raw boundary evidence.
