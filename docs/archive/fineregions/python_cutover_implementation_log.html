The plan treats the existing region partition and fractional payload as the foundation, then enumerates the missing pieces required to restore a fully functional rigel quant: every-region gDNA estimation, global aggregation, regional exposure, per-locus prior assembly, pipeline re-entry, test-gate removal, documentation updates, and benchmark validation.

FL estimation stress + policy cleanup (2026-05-22)

Added scripts/sim/fl_estimation_stress.py and documented results in fl_estimation_stress_2026-05-22.md. The oracle mini-genome matrix confirmed that raw RNA/gDNA FL histograms are accurate in the good branch, but also exposed two policy problems: add-one-per-bin smoothing pulled scoring PMFs toward the histogram midpoint, and fixed weak-branch EB shrinkage could erase low-support channel-specific FL separation.

Implemented the simpler policy: FragmentLengthModel.finalize() now uses one total unseen-bin pseudo-observation, finalized summary stats use the same PMF as scoring, and weak FL pools use logarithmically capped global EB shrinkage. The default weak threshold is now 1, so non-empty RNA or gDNA pools remain informative unless the caller explicitly raises the fallback threshold.

Phase 4 contained density + strand variance start (2026-05-22)

Restored the first non-stub density_global.py implementation for the fractional path. compute_global_densities now consumes RegionArrays + PayloadArrays, selects intergenic regions with signature == 0, selects intron-only regions with intron bits set and no exon bits, and estimates density from contained unspliced fractional mass divided by FragmentLengthModel.compute_all_transcript_eff_lens effective length. Exon and mixed exon/intron densities remain explicit placeholders for later Phase 4 work.

Added StrandBalanceEstimate, a symmetric beta-binomial strand overdispersion diagnostic with mean fixed at 0.5 and only kappa estimated. The method-of-moments formula mirrors the simulator's Beta(kappa/2, kappa/2) regional strand model. When observed residual variance does not exceed binomial expectation, the estimator reports a large binomial-like kappa with a fallback reason rather than moving the mean away from 50/50.

_orchestrator.calibrate now builds sorted PayloadArrays, calls compute_global_densities, and returns a non-null global_densities block while keeping regional exposure uniform and prior assembly fail-fast. Re-enabled the refreshed FL and orchestrator tests in conftest.collect_ignore, and added tests/test_fractional_density_global.py.

Peculiarity: mappability is still absent from region denominators. The surviving index knobs (alignable_zarr_path, mappability_read_length) feed the splice-junction artifact blacklist; the manifest still records mappability: null and no per-region alignable-base table is loaded.

Full-suite validation exposed three stale FL-policy tests that still expected add-one-per-bin smoothing or raw-count median semantics. Refreshed those expectations to the one-total-pseudo-observation scoring PMF and finalized-statistics contract.
