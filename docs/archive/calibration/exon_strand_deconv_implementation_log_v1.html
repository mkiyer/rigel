Phase 1: Payload Surface

Completed. Added exon_contained_counts_by_orient to the native calibration payload, worker merge, Python export dict, CalibrationScanPayload, and sorted PayloadArrays.

Counting rule implemented. Native counting is restricted to unique non-artifact observations that reach observe(), are unspliced, have obs_mask == EXON, hit an EXON region, and have exact half-open containment [frag_start, frag_end) <= [region_start, region_end).

Issue encountered. The new schema touched several direct test payload constructors. These were updated with zero-filled EXON-contained arrays so existing tests keep their old semantics.

Open question. None for Phase 1. The payload contract is now available for global density implementation.

Phase 2: Global Density

Completed. Added the global EXON-CONTAINED density channel and a precision-weighted EXON-COMPOSITE projection density.

Theory implemented. The composite uses strand_power = signed_strand_contrast^2, converts kappa alpha to bp opportunity with beta = alpha / rho, and fuses boundary/contained evidence through E * beta / (E + beta) precision.

Design guardrail. EXON-contained evidence contributes only when strand correction is active and strand-identifiable rows are present. Unstranded and AMBIG-only EXON-contained rows remain diagnostic and the composite falls back to boundary flux.

Verification. pytest tests/test_density_global.py -v passed with 27 tests, including pure RNA, pure gDNA, unstranded fallback, AMBIG fallback, and kappa-capped precision fusion cases.

Open question. None for Phase 2. Regional exposure can now consume the composite EXON projection density.

Phase 3: Regional Exposure

Completed. Regional exposure now builds EXON rows from separate boundary and EXON-contained evidence streams, then combines them through the same kappa-capped precision model used by the global composite.

Bias guardrail implemented. EXON-contained signed moments are carried through shrinkage and final per-row rates are floored afterward, with n_negative_rho_floored recorded in the exposure summary.

Diagnostics expanded. per_class now includes EXON-INTRON, EXON-CONTAINED, and EXON-COMPOSITE summaries so boundary-only, contained-only, and actual composite evidence can be audited separately.

Verification. pytest tests/test_regional_exposure.py -v passed with 17 tests, including contained-only EXON exposure, unstranded fallback, and negative signed-moment flooring.

Open question. None for Phase 3. The remaining implementation is locus-prior fusion and final focused regression testing.

Phase 4: Locus Prior Fusion

Completed. Added locoregional EXON-contained strand evidence and fused it with the existing boundary branch for diagnostic per-locus gDNA estimates.

Canonical prior preserved. expected_gdna_count_global() remains payload-free. Boundary-crossing expected counts still use global_densities.exon_intron.rho; EXON-contained projection now uses global_densities.exon_composite.rho.

Diagnostics added. Per-locus estimates now carry nested ExonGdnaDiagnostics with boundary rate, contained rate, fused rate, precision weights, and contained evidence counters. Existing EM-facing arrays remain unchanged.

Issue encountered. Existing exact-count tests use kappa=0, which makes the precision formula evaluate to zero. Added explicit boundary-only and contained-only fallbacks so exact local modes preserve legacy behavior when one branch is inactive.
