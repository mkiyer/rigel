gDNA Regional Exposure v4.3 Implementation Digest

Date: 2026-05-19

Goal: implement the denominator-only regional exposure model from docs/calibration/gdna_exposure_plan_v4.3.md.

StepStatusDetails

Implementation Core code complete Implemented the global exposure field, shared footprint weights, EM/output transcript length split, gDNA EM prior rescaling, and removed production numerator mutation.

The full suite passed after refreshing intentional golden outputs: 1097 passed. Project-wide Ruff also passed.

Successful Details

  • No native EM ABI change appears necessary: C++ already accepts transcript effective lengths, gDNA effective lengths, and gDNA prior counts as arrays.
  • The existing RegionalGdnaExposure.weighted_length_on_ref primitive can support footprint-average exposure weights.
  • The existing index exon CSR can support mRNA exon-block footprints.
  • RegionalGdnaExposure.build now computes one global rho_global, one global kappa_global, one global rho_ref, and one exposure field.
  • AbundanceEstimator now stores raw public transcript lengths separately from EM transcript lengths.
  • PriorTable now carries both raw gdna_prior_count and EM-rescaled gdna_prior_count_em.
  • The production call to _apply_unit_gdna_weights has been removed; regional exposure is denominator-only.

Problems And Issues

  • The old implementation's rho_ref_per_class, signal_per_class, and numerator mutation paths must be removed from production behavior.
  • The old class-reference and class-signal fields have been removed from production exposure construction.
  • Existing tests expect gdna_prior_count_regional; v4.3 replaces that with gdna_prior_count_em and exposure-weight diagnostics, so tests need updates.
  • Focused tests have been updated for gdna_prior_count_em, gdna_em_exposure_weight, and transcript EM length diagnostics.
  • Ruff passed on all touched source and test files.
  • Full-suite run before golden refresh had 4 failures in tests/test_golden_output.py; the differences were transcript count shifts in gDNA/combined scenarios, consistent with the intentional denominator-only regional exposure change. After --update-golden, the golden suite and full suite passed.

Open Questions Not Resolved Ahead Of Time

  • Whether exact fragment-midpoint integration for gDNA denominators will be needed after the simpler footprint-average model passes or fails VCaP gates.
  • Whether the three gDNA evidence channels are sufficiently calibrated onto one common global field in real hybrid-capture data.
